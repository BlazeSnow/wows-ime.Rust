# WOWS-IME

[简体中文](README.md) | [繁體中文](README.zh-Hant.md) | 日本語

## 概要

> [!TIP]
> アプリの詳細については、公式サイトをご覧ください：<https://wows.blazesnow.com/ja/>

World of Warships の日本語入力設定ファイルを編集し、より多くの入力メソッドを使えるようにするツールです。

UI は簡体字中国語、繁体字中国語、日本語の 3 言語に対応しています。
