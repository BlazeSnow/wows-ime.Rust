# wows-ime

《战舰世界》中文输入法配置文件修改器

## 程序介绍

本程序针对游戏《战舰世界》的中文输入法的配置文件，目的为修订配置文件以支持更多的中文输入法。

程序会扫描你系统中已启用的中文与日文输入法，由你勾选需要添加的部分并指定分类（中文简体 / 中文繁体 / 日文），再写入游戏的 `ime_config.xml`，游戏内即可切换到这些输入法。

## 使用方法

1. 在「主页」的第 1 步选择游戏根目录：可直接选预设路径（Steam / Lesta / 360），或用「添加自定义路径」指定其它安装位置。
2. 在第 2 步勾选要写入的输入法，并按需要调整每项的分类；也可添加游戏没有收录的自定义输入法。
3. 在第 3 步确认无误后点击「写入配置」，程序会把配置文件写入游戏目录下 `bin` 中的各个版本目录。
