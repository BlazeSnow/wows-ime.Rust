# 测试基线

## 命令

```powershell
cargo test           # 后端（src-tauri），当前 27 项
pnpm test            # 前端（vitest），当前 10 项
pnpm check:locales   # 三语资源一致性
```

交付前必须全部通过。

## 后端测试（Rust）

| 位置 | 覆盖内容 |
| --- | --- |
| `error.rs` | 错误码序列化形状（前端从 rejection 中读 `{ code }`，是对外契约） |
| `state.rs` | 数据目录与设置库路径 |
| `storage.rs` | 建表幂等、设置默认值与 upsert、自定义路径/输入法读写、全量同步的删除语义、旧 `config.json` 迁移与改名、迁移只发生一次 |
| `gameconfig.rs` | 空选择的三个空分组、分组顺序（简体→日文→繁体）、每项三元素与 Tag、名称 XML 转义、数字版本目录筛选、UTF-8 无 BOM 写入、游戏 exe 校验 |
| `models.rs` | 分类字符串往返、未知分类回退、字段 camelCase 序列化 |
| `scanner.rs` | 目标语言 ID 过滤、语言 ID 与名称关键词推断分类、噪音项过滤、真实系统扫描的结构冒烟 |

### 注意事项

- 扫描类测试依赖真实系统输入法配置，只断言结构（唯一性、排序），不断言具体条目。
- 涉及文件系统的测试使用临时目录并在结束时清理。

## 前端测试（vitest + Testing Library）

| 位置 | 覆盖内容 |
| --- | --- |
| `i18n.test.ts` | 语言模式归一化、系统语言推断（含繁体/简体/日文/回退） |
| `i18n.interpolation.test.ts` | `{0}` 占位符插值、多占位符、未知键回退 |

## 手工验收清单

发布前在真机上逐条确认：

- [ ] 扫描能列出系统已启用的中文/日文输入法，分类推断正确
- [ ] 三种预设路径可选择，自定义路径可添加、删除（删除有确认框）
- [ ] 自定义输入法可添加、删除，分类可切换且重启后保留
- [ ] 写入前有覆盖/新增确认，取消后不写文件
- [ ] 写入后 `bin\<数字版本>\res_mods\ime_config.xml` 内容正确、UTF-8 无 BOM
- [ ] 游戏内可切换到所选输入法
- [ ] 三语界面完整，切换立即生效且重启后保留
- [ ] 从旧 WinUI 3 版本启动后，旧的游戏路径与自定义输入法被迁移，旧文件改名为 `config.json.migrated`
