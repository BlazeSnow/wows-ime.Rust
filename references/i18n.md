# 多语言

界面语言支持简体中文（`zh-Hans`，默认）、繁体中文（`zh-Hant`）与日语（`ja`），共 91 个文案键，三语键集合与占位符完全一致。

## 选型

| 层 | 方案 |
| --- | --- |
| 前端 | i18next + react-i18next |
| 后端 | 无用户可见文案，暂不引入 fluent-i18n |

后端的错误以稳定错误码（如 `ErrorNoInputMethodSelected`）返回，由前端映射为本地化文案；需要时再引入 fluent-i18n。

## 资源文件

- 位置：`src/locales/{zh-Hans,zh-Hant,ja}.json`
- 格式：扁平键值对，键名为点号/斜杠分隔的语义路径（如 `Status/WriteSucceededWithCount`）
- 来源：由原 WinUI 3 版本的三份 `Resources.resw` 转换而来，键名与文案完全沿用原版

## i18next 配置要点

| 配置 | 值 | 原因 |
| --- | --- | --- |
| `keySeparator` | `false` | 键名含 `.` 与 `/`，需整体查表而非逐级解析 |
| `nsSeparator` | `false` | 同上 |
| `interpolation.prefix` / `suffix` | `{` / `}` | 原版文案用 `{0}` 单花括号占位，不是 i18next 默认的 `{{0}}` |
| `interpolation.escapeValue` | `false` | 文案由 React 转义，无需二次转义 |
| `returnEmptyString` | `false` | 空值回退到 fallback 语言 |
| `fallbackLng` | `zh-Hans` | 默认语言 |

占位符按数字索引传参：`t("Step/Progress", { 0: step, 1: total })`。

## 语言模式

- 取值：`auto` / `zh-Hans` / `zh-Hant` / `ja`，与原版 `LanguageRules` 一致。
- `auto`：按系统语言列表依次判断——
  - 繁体变体（`zh-Hant` / `zh-TW` / `zh-HK` / `zh-MO`）→ `zh-Hant`
  - 其余中文变体（`zh-Hans` / `zh-CN` / `zh-SG`）→ `zh-Hans`
  - `ja` / `ja-*` → `ja`
  - 都不匹配 → 回退 `zh-Hans`
- 模式持久化在 `settings.Settings.Language`，未设置时为 `auto`。

## 切换行为

Tauri 版切换语言**立即生效**（i18next 运行时切换），不需要像原版 WinUI 那样重启应用；切换结果同时写入设置库。

## 一致性校验

`node tools/check-locales.mjs`（`pnpm check:locales`）校验三条规则：

1. 单个语言文件内键不重复；
2. 各语言的键集合完全一致；
3. 每个键的占位符集合一致。

新增或修改文案时必须同步三份资源，并在交付前跑通校验。

## 注意事项

- 后端返回的 `Tsf/*` 警告码在资源中同名存在，前端按警告码直接查表，查不到时回退显示警告码本身。
- 用户可见文案零硬编码：组件里不写死中文，也不写死英文。
