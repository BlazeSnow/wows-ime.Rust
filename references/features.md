# 功能

wows-ime 是《战舰世界》的中文输入法配置修改器：扫描系统已启用的中文/日文输入法，把用户勾选的部分写成游戏的 `ime_config.xml`，让游戏在输入时能切到这些输入法。

## 用户流程（三步向导）

### 第 1 步 · 游戏根目录

- 三个预设路径单选项：Steam（国际服）、Lesta（俄服）、360（国服）。
- 支持添加自定义路径（系统目录选择器），可删除自定义路径（删除前弹窗确认）。
- 支持直接打开选中的目录。
- 选中项与自定义路径都会持久化，下次启动恢复。

### 第 2 步 · 输入法选择

- 列出系统已启用的中文/日文输入法，每项可勾选。
- 每项可切换分类（中文简体 / 中文繁体 / 日文），分类决定写入哪个 `<Tag>` 分组。
- 支持添加自定义输入法（名称 + 类型），可删除自定义输入法（删除前弹窗确认）。
- 支持重新扫描系统输入法。

### 第 3 步 · 确认写入

- 汇总展示游戏根目录与已选输入法（含序号与分类）。
- 写入前二次确认：
  - 目标目录已有 `ime_config.xml` → 提示覆盖数量；
  - 完全没有 → 提示将新增的数量。
- 写入结果以成功/失败提示反馈，写入成功时给出实际更新的文件数量。

## 约束

- 游戏根目录必须存在游戏可执行文件：国服 `WorldOfWarships.exe`、俄服 `Korabli.exe`。
- 写入位置由 `<游戏根目录>\bin\` 下的**数字版本目录**决定；版本号随游戏更新变化，因此不得硬编码任何版本号。
- 若 `bin` 下没有数字版本目录，则无法确定写入位置，直接报错终止。

## 明确不做

- 不做游戏安装检测、不做自动下载、不做多游戏实例管理。
- 不修改游戏其它文件，只写 `ime_config.xml`。
